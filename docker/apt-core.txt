# 基础镜像预置的 apt 包清单（一行一个，注释与空行忽略）。
#
# 选包原则：只放 Debian bookworm 官方源里确实存在的包。
# 不存在的包名会让整条 apt-get install 失败，镜像直接构建不出来——
# Kali 专有包（exploitdb / feroxbuster / nikto）和第三方源包不进这份清单。
# 每次改动都在 debian:bookworm-slim 里跑一遍
#   apt-get install --dry-run $(grep -v '^#' docker/apt-core.txt)
# 确认没有 "Unable to locate package" 再提交——CI 的镜像构建就是被 nikto 卡住的。
#
# 体积敏感件单独说明：
#   tshark        约 100MB（含 wireshark-common），是这份清单里最大的一件
#   smbclient     约 20MB（含 samba-common）
#   whatweb       约 30MB（ruby 运行时）
# 合计约 350-400MB。
# 重量级工具（hashcat/john/gdb/binwalk/exiftool/awscli/xfreerdp）不在这里，
# 在 docker/apt-tools.txt —— 那份清单逐件安装、单件失败只告警，体积也更大。
